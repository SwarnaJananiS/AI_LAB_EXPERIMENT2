# AI_LAB_EXPERIMENT2
AI Lab Experiment using Python
 Experiment 2: Electricity Billing System Using Conditional Statements and Loops

Aim:
To develop a Python-based electricity billing system that calculates energy consumption charges using slab rates, conditional statements, and loops.

Concepts Used:
- Python functions
- Conditional statements ("if", "elif", "else")
- Loops
- Arithmetic calculations
- User input and output

Description:
The program accepts the number of customers, their names, and electricity units consumed. It calculates the bill according to the applicable unit-based slab rates and displays the customer details and bill amount.

Electricity Slab Rates
Units Consumed| Rate per Unit
First 100 units| ₹1.50
Next 100 units| ₹2.50
Next 300 units| ₹4.00
Above 500 units| ₹6.00

How to Run:
python experiment2.py

Sample Output:
Enter number of customers: 1

Customer 1
Enter customer name: Arun
Enter units consumed: 350
Customer Name : Arun
Units : 350.0
Bill Amount : Rs. 1000.0

Result

The electricity billing system using conditional statements, loops, and slab-based calculations was implemented successfully.
